# docs/

Everything written rather than executed.

## Files

| File | Responsibility |
|------|----------------|
| `references.md` | Working reference list with a verification status per entry. Nothing is cited while still marked "confirm" |
| `dataset-card.md` | Written: source, per-corpus counts, class balance, duplicate rate, licence and access conditions, known limitations |
| `report/outline.md` | Structure of the 30-mark theory component, section by section |
| `report/` | The report draft itself, plus the desktop-app screenshot and any exported figures |
| `ITRI625_Project_ML fin.pdf` | The original project brief, kept with the repository so no session has to go looking for it |

## Rules

- The brief PDF is the authority. Where this repository and the brief disagree,
- A reference goes into the report only after its page has been opened and its
  claims read. `references.md` tracks that per entry.
- The report is written, after the results exist. Drafting it
  earlier produces claims the results then have to be bent to fit.
